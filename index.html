04 — Automation Engineering

End-to-end automation & tooling

AI-driven tools and scripted workflows built to remove manual effort from migration, approvals, and infrastructure visibility.

Power Automate + Python

OS & Application Migration Automation

Built an end-to-end automation tool combining Power Automate and Python scripting to drive OS and application migrations with minimal manual touch.

  • Enter the server names and the tool automatically emails the application/VM owner for approval — no manual chasing.
  • Once approved, it integrates with ServiceNow (via MCP) to auto-raise the change, notify stakeholders, and run the migration end-to-end — including steps like copying files from Artifactory to the target repo.
Example · Ran a batch server migration through the tool end-to-end and cut a multi-day manual approval-and-handoff process down to hours.
Unified Visibility

Central Infrastructure Dashboard

Designed and built a central dashboard mapping every component across the infrastructure — VMware clusters, hosts, VMs, Azure resources, and applications — into one live view for faster triage and decision-making.

  • Pulls inventory and health status from VMware, Azure, and ITSM sources into a single pane of glass.
  • Gives stakeholders real-time visibility into infra dependencies without manually cross-checking multiple tools.
Example · Spotted a datastore approaching capacity on the dashboard and resolved it proactively, before it could affect running VMs.
ChatGPT + GitHub Actions

AI-Assisted L1 Troubleshooting & Escalation Tool

Designed, built, and self-hosted a triage assistant that pairs ChatGPT with GitHub Actions to speed up first-line troubleshooting — takes the guesswork out of finding where an issue is actually starting from.

  • Runs an initial diagnostic pass on the reported issue and points L1 straight at the likely root-cause area, instead of them starting from zero.
  • Integrated with the ServiceNow CMDB to auto-pull server owner, support team, and managed-by details, and surfaces the right person to escalate to — cutting out the back-and-forth that used to slow engagement down.
Example · Cut the time to identify the right team to escalate a production incident to from roughly 30 minutes of manual lookup down to under 2 minutes.
